# MobileIntelligence
An open-source Swift SDK for integrating AI into mobile applications with a provider-agnostic architecture.

✨ Provider Agnostic
Integrate OpenAI, Anthropic, Gemini, Ollama, Azure OpenAI, and more through a unified API.

📦 Modular
Use only the components your application needs.

⚡ Swift Native
Built with modern Swift, Swift Concurrency, and Swift Package Manager.

🔌 Extensible
Add custom AI providers, tools, and plugins with minimal effort.

📱 Mobile First
Designed specifically for iOS and Apple platforms with performance and battery efficiency in mind.

🚀 Future Ready
Built to evolve from prediction APIs to intelligent AI agents and workflows.
